# C语言通讯录管理系统简介

## 核心功能
- 显示通讯录
- 查找通讯录
- 添加通讯录
- 按姓名排序通讯录
- 删除通讯录
- 保存记录到文件

## 适用场景
- 个人或小团队管理联系信息
- 教学示例，用于学习C语言编程
- 简单的数据库管理需求

## 技术特点
- 使用C语言编写，具有良好的跨平台性
- 简单易用的命令行界面
- 实现了基本的文件读写操作
